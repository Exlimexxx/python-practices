# Лабораторная работа №6: Разработка консольного приложения «Кинотеатр»

## Структура проекта
* `models.py` — Модели данных (`Movie`, `Hall`, `Session`), иерархия наследования, `dataclass`, `Enum` (`SessionStatus`) и пользовательские исключения.
* `protocols.py` — Определение протокола `Reportable` и функции проверки соответствия протоколу.
* `decorators.py` — Реализация трёх декораторов: `@log_call` (журналирование), `@measure_time` (замер времени) и `@repeat` (декоратор с параметром).
* `context.py` — Контекстный менеджер `SessionTransactionContext` для обеспечения транзакционности изменений данных.
* `services.py` — Основная бизнес-логика (`CinemaService`), алгоритмы расчёта статистики (через `map`, `filter`, `sorted`, `any`, `all`) и модуль интроспекции `inspect_object`.
* `main.py` — Консольное меню, обработка исключений и демонстрационный сценарий.

## Запуск приложения
```bash
python main.py
