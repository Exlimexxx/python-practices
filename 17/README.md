# Лабораторная работа №17 — Telegram-бот кинотеатра (вариант 4)

## Запуск
1. Создать виртуальное окружение и установить `pip install -r requirements.txt`.
2. Скопировать `.env.example` в `.env`, экспортировать `BOT_TOKEN` и `ADMIN_IDS` в окружение.
3. Запустить `python bot.py`.
4. Проверить бизнес-логику: `python -m pytest -v`.

Токен не хранится в исходном коде. База SQLite создаётся автоматически; демонстрационная база содержит связанные жанры, фильмы, залы, сеансы и билетные записи. Команды администрирования: `/addmovie Название|Жанр|Длительность|Рейтинг`, `/editmovie ID|Название|Жанр|Длительность|Рейтинг`, `/deletemovie ID`.
